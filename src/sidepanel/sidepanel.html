Connect OpenCode

Start the local OpenCode server in PowerShell with a password you choose and the Agent Smith profile.

$env:OPENCODE_SERVER_PASSWORD = 'your-password'
$env:OPENCODE_CONFIG_CONTENT = '{"agent":{"agent-smith":{"description":"Browser planner","mode":"primary","permission":"deny"}}}'
opencode serve --hostname 127.0.0.1 --port 4096

Save the server address and password above, then select a browser sign-in method below. For providers that need additional setup, use opencode auth login.
